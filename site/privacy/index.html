Privacy

Critter Overlay has no accounts, no ads and no telemetry. What it knows stays on your computer.

What the app keeps, and where

Everything lives in one folder in your Windows user profile: %APPDATA%\Critter Overlay.

  • settings.json: your settings.
  • economy.json: your progress. That is your berries, focus minutes, gifts, the things you own and what your critters wear, your Collection and sightings, and bonds.
  • custom: the homemade critters you make or import. Pictures are saved again as plain PNG, so nothing but the pixels is kept: no location or camera details from a photo.
  • updates: a downloaded update, waiting to install.
  • logs: the app's log, which stays there unless you copy it for a bug report.

Saves go to a temporary file first, and the previous save is kept as a .bak copy, so a crash can't lose your progress. If you used version 2, the app copies its settings and custom critters across from %APPDATA%\CritterOverlay.

Uninstalling asks whether to delete this folder too. The default keeps it, so a reinstall carries on where you left off.

How it knows you're at your desk

It asks Windows how long it has been since the last key press or mouse movement. It never records which keys you press, what you type or where you click. To hide during full-screen games, films and presentations, it asks Windows whether one is running; it doesn't look at what is on your screen.

Copy diagnostics

Settings › System › Help › Copy diagnostics puts your version, screens, settings and the recent log on your clipboard, for a bug report. Nothing is sent unless you paste it somewhere yourself.

What goes over the internet

The app makes one connection of its own: the update check.

  • Once a day it asks GitHub for the newest release of Critter Overlay, at api.github.com/repos/hstagg/critter-overlay/releases/latest.
  • The request carries the app's version number (for example CritterOverlay/3.1.1) and, after the first check, a tag that lets GitHub answer “nothing new” cheaply. It carries no ID, no settings and nothing about your critters.
  • When there is a newer version and Automatic updates is set to Download for me, the installer downloads from GitHub and is checked against the SHA-256 hash GitHub publishes before it runs. It installs only when you say, or when you quit.
  • Settings › System › Updates › Automatic updates has three choices: Off, Tell me and Download for me. With Off, it checks only when you press Check now.

As with any web request, GitHub sees your IP address. GitHub's privacy statement covers what it does with it.

Links in the app, such as Help and What is new, open in your web browser.

This website

  • It sets no cookies, runs no analytics and loads nothing from other sites.
  • It is hosted on GitHub Pages, which may log visitors' IP addresses for security, under the same GitHub privacy statement.
  • When you follow a link to itch.io, your browser tells itch.io which page of this site you came from. That is the page's address and nothing about you. It lets itch.io's own statistics show which links people follow. Short links such as /c/…/ are there for this: they send you straight on to itch.io.
  • Downloads and tips happen on itch.io, under itch.io's privacy policy.
