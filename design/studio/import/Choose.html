How to make a critter
No layers in drawing.svgIt's all one picture, so the parts can't move on their own. Start from a template and keep each part on its own layer. Or, to use it as it is, bring it in as a picture.
These layers are the wrong sizeThey're 512 x 480. The template is 300 x 280, or an exact multiple such as 600 x 560 or 900 x 840. Export the whole canvas for every layer, untrimmed.

What each file becomes
Drawn An SVG with a layer per part. A folder or zip of PNG layers. An .ora file. Photoshop (.psd) files can't be read: export the layers as PNGs first.
Animated A GIF or animated PNG. A sprite sheet. An Aseprite file. A folder of numbered frames.
Picture One PNG, JPG or WebP picture. Its background is taken out and it slides along.
From someone A .critter file, or a code that starts CRIT1-. You see it walk before anything is added.
