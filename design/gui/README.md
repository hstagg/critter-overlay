# v3 GUI design source

Generator for the "Critter Overlay v3 GUI" design canvas (settings pages, tray panel, toasts, onboarding, foundations, notes). `theme.py` holds the colour tokens, light and dark, and the rarity tier colours; the Godot Theme resources should be built from it so the app matches the design. `build.py` assembles the artboards from `parts.py` and `pages1-4.py`.
